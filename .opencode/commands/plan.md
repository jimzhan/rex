---
name: plan 
description: Convert a feature request into a detailed specification, then break it down into actionable development tickets.
disable-model-invocation: true
---

Orchestrate a two-step planning process:

1. **Run `/to-spec`**: Start a specification session to analyze the requirement and generate a comprehensive technical plan.
2. **Run `/to-tickets`**: Once the specification is finalized, use this skill to decompose the generated plan into granular, well-defined tickets (e.g., tasks, subtasks, or Jira items).

Ensure the `/to-spec` session completes fully before initiating `/to-tickets` to guarantee the plan is stable and detailed enough for accurate ticket breakdown.
